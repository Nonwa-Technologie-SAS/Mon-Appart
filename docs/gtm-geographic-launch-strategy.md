## 1. Principe

Lancer **géographiquement concentré** pour atteindre une densité d’annonces utiles, plutôt qu’une couverture CI diluée.

Critères de sélection (pondération indicative) :

| Critère                                | Poids relatif | Mesure                                        |
| -------------------------------------- | ------------- | --------------------------------------------- |
| Demande observable (portails / presse) | Élevé         | Volume annonces concurrentes, mentions marché |
| Facilité d’acquisition offre           | Élevé         | Accès agences / propriétaires                 |
| Diversité de budgets                   | Moyen         | Mix standing / moyen                          |
| Concurrence locale                     | Moyen         | Présence portails (surmontable si qualité)    |
| Capacité vérif / ops                   | Élevé         | Temps équipe                                  |
| Potentiel contacts utiles              | Élevé         | Profil demandeurs vs offre                    |

## 3. Zones pilotes proposées

### Phase géo A (recommandé)

1. **Cocody** (incl. sous-zones Riviera / Angré selon capacité)
2. **Marcory**

**Justification :** densité d’annonces concurrentes = preuve de liquidité ; budgets permettant une offre photographiable ; alignement avec focus location LD standing/moyen-haut ; capacité à recruter agences déjà actives en ligne.

**Ce n’est pas** « parce que Cocody est prestigieux » seul — c’est la combinaison densité + accessibilité commerciale + matching possible.

### Phase géo B (extension conditionnelle)

3. **Yopougon** — si critères extension atteints (ci-dessous) et capacité vérif OK.

### Hors scope initial

- National CI, Bouaké/intérieur (volumes ventes en hausse presse mais ops distantes).
- Terrains Bingerville comme pilote principal.

## 4. Critères d’extension géographique

Passer à une nouvelle commune seulement si **tous** :

| Indicateur                               | Seuil provisoire (hypothèse ops — à recalibrer)                                  |
| ---------------------------------------- | -------------------------------------------------------------------------------- |
| Annonces actives vérifiées zone courante | ≥ 40 (ou densité permettant ≥3 résultats pertinents pour scénarios budget types) |
| Taux réponse contact 48 h                | ≥ 40 %                                                                           |
| Signalements fraude / spam               | &lt; seuil défini ops                                                            |
| Charge modération                        | SLA tenus                                                                        |
| Demande locale                           | Recherches / contacts non nuls sur 14 j                                          |

Si non : **approfondir** la zone, ne pas élargir.
