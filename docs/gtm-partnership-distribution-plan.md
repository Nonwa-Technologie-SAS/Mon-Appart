## 2. Programme d’onboarding partenaire (léger)

1. Qualification (zone, volume, qualité photos).
2. Démo + fiche partenaire 1 page.
3. Accord d’usage (droits photos, exactitude, retrait).
4. Création compte AGENCY + vérif identity si process.
5. Première publication accompagnée.
6. Formation réponse aux leads (24–48 h).
7. Point perf J+7 / J+30.
8. Décision renew / pause.

Import CSV / webhooks : uniquement avec droits — voir docs partners techniques. **Pas de scraping** d’autres portails.

---

## 3. Fiche partenaire (structure)

- Nom / contact / zones / nb biens
- Offre Mon Appart au pilote (gratuité, support)
- Engagements qualité
- Données partagées / non partagées
- Indicateurs suivis
- Durée pilote 30–90 j
- Sortie
