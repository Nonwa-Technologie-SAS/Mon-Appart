# Onboarding partenaires

## Priorité 1 — Agences

1. Compte utilisateur + rôle `AGENCY` (admin `role:manage`).
2. Vérification Trust type agence si exigée.
3. Publication via APIs / espace existants (`listing:create`, `listing:publish`).
4. Stats : `analytics:read` + dashboard éditeur.
5. Optionnel : fiche `Partner` + webhook out pour leur SI.

## Priorité 2 — Propriétaires / gestionnaires

Parcours `/inscription/proprietaire` + espace web (legacy) ou APIs Nest OWNER.

## Priorité 3 — Promoteurs

Évaluer si `Property`/`Listing` suffisent pour programmes/lots avant tout modèle dédié.

## Priorité 4 — Prestataires

Uniquement si valeur UX claire et contrôles qualité possibles.

## Indicateurs d’onboarding

Partenaires enregistrés / commercialement ACTIVE / intégration ACTIVE / annonces acceptées / contacts générés — voir [partner-distribution-strategy.md](./partner-distribution-strategy.md).

L’enregistrement technique **ne remplace pas** la négociation commerciale.
