## 3. Matrice comparative

### Fonctionnalités communes du marché (observables)

- Catalogue annonces location / vente / terrains
- Filtres ou navigation par localisation
- Affichage prix FCFA
- Mise en avant / « à la une »
- Distinction particulier / professionnel (variable)
- Contact (téléphone / formulaire — détails variables)
- Contenu SEO local (prix, guides) chez IvoireDomi / Keur / Batirici

### Points faibles observables (marché)

| Faiblesse                          | Preuve / indice                            | Opportunité Mon Appart                    |
| ---------------------------------- | ------------------------------------------ | ----------------------------------------- |
| Qualité hétérogène des fiches      | Surfaces/prix parfois absurdes en listing  | Contrôle qualité avant publish            |
| Sur-revendications « N°1 »         | Marketing sans métrique publique           | Positionnement sobre et prouvé            |
| Distraction multi-segments         | Même page : bureaux, terrains, villas luxe | Focus segment pilote                      |
| Confiance floue                    | Badges sans définition claire              | Niveaux de vérif explicites               |
| Charge multi-portails pour agences | Plusieurs acteurs B2B                      | Valeur = leads utiles, pas présence seule |

### Différenciation potentielle Mon Appart

| Avantage potentiel                    | Validé produit ?                   | Validé marché ? |
| ------------------------------------- | ---------------------------------- | --------------- |
| Recherche + critères budget / besoins | Partiel (search + assistant flags) | Non             |
| Recommandations personnalisées        | Partiel (flags)                    | Non             |
| Trust / signalements / badges         | Partiel (module Trust)             | Non             |
| UX mobile adaptée                     | À mesurer                          | Non             |
| Matching contact qualifié             | Contact code présent               | Non             |

**Ne pas vendre « l’IA » :** vendre **moins de temps perdu** et **moins de contacts inutiles**, si les tests le confirment.

## 5. Implications stratégiques

1. **Ne pas attaquer frontalement** sur volume national d’annonces au jour 1.
2. **Gagner une zone + un segment** (location LD Cocody/Marcory) avec qualité.
3. **Terrains** = forte présence concurrente + risque confiance → différer ou niche contrôlée.
4. **Agences** : Batirici déjà positionné B2B → Mon Appart doit apporter **prospects qualifiés** mesurables.
5. Contenu SEO utile seulement **après** densité d’offre réelle (éviter pages vides).
